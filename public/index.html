Tickets digitales, simples y validables.

Ticket Schema es un estándar abierto JSON Schema para tickets, recibos y comprobantes digitales. Sirve para reemplazar papel físico con documentos portables, verificables y fáciles de renderizar.

Uso rápido

Flujo mínimo para integrar Ticket Schema en una app.

1. Crear JSON 2. Validar 3. Render JSON 4. Render HTML 5. Iframe

1. Crear un documento

Genera un JSON compatible con uno de los perfiles v0.1.

{
  "$schema": "https://ticketschema.org/schema/v0.1/profiles/retail-receipt.json",
  "ticketSchemaVersion": "0.1",
  "documentType": "retail_receipt",
  "status": "paid",
  "currency": "MXN",
  "amounts": { "total": 86, "paid": 86, "balance": 0 }
}

2. Validarlo

POST https://ticket-schema.pages.dev/api/validate
content-type: application/json
{ "valid": true, "errors": [] }

3. Obtener HTML dentro de JSON

POST https://ticket-schema.pages.dev/api/render
content-type: application/json

{
  "document": { "...": "Ticket Schema JSON" }
}
{
  "valid": true,
  "errors": [],
  "html": "<div class=\"ticket-schema-render\">...</div>"
}

4. Obtener HTML directo

POST https://ticket-schema.pages.dev/api/render/html
content-type: application/json

{
  "document": { "...": "Ticket Schema JSON" }
}

Responde text/html, listo para previsualizar o insertar.

5. Embed por URL

Si el documento ya está publicado como JSON, usa el renderer embebible.

https://ticket-schema.pages.dev/render/?src=/examples/v0.1/retail-receipt-mx.json
<iframe src="https://ticket-schema.pages.dev/render/?src=/examples/v0.1/retail-receipt-mx.json"></iframe>

Apps compatibles pueden mostrar: Validated by Ticket Schema. API técnica completa en /api/validate, /api/render y /api/render/html.
